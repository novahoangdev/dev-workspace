# CV Review
Review role positioning, first-scan clarity, hierarchy, achievements vs responsibilities, supported quantified impact, repetition, relevance, chronology, consistency, ATS-friendly structure, length, density, and factual integrity. Never fabricate stronger evidence. Separate must-fix from optional improvements.
