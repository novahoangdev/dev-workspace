# CV Web Design

## Goal
Help a recruiter quickly understand who the person is, what role they fit, and what evidence supports that positioning.

## Priorities
- Make name, role/specialization, strongest evidence, experience, selected work, CV access, and contact easy to find.
- Optimize the first scan before adding detail or decoration.
- Prefer concrete work and verified outcomes over decorative skill scores or unsupported claims.
- Keep chronology, labels, dates, and career facts consistent with the source of truth.
- Make portfolio/project links and CV download/print actions obvious and trustworthy.
- Balance personality with professional readability; avoid turning the page into a generic resume template.

This is a domain specialization, not a general UI checklist. Use the coding client’s native frontend capabilities for composition, responsive behavior, accessibility, and implementation. Do not automatically load `career-content`, `cv-review`, or other skills; use them separately only when their specialized workflow is explicitly needed.
