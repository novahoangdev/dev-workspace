# Feature Planning
Inspect before planning. Read repository instructions/docs and relevant code first.

Produce: goal, current-state observations, requirements, non-goals, proposed approach, affected areas, risks/edge cases, verification strategy, ordered implementation steps, and only material open questions.

Prefer existing architecture and the smallest maintainable approach. Planning does not authorize implementation, commit, push, deploy, or destructive actions.
