# PDF Quality
Confirm the PDF exists/opens; inspect page count/size, file size, text extraction and links when possible; render every page when possible; visually inspect margins, clipping, overflow, alignment, page breaks, blank pages, fonts, headers/footers, and hierarchy; confirm expected key content.

Return PASS, PASS WITH CAUTIONS, or FAIL. Never claim visual inspection occurred if pages were not rendered/viewed.
