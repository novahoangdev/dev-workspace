# SEO Audit
Check titles/descriptions, canonical URLs, robots/sitemap, crawlable/indexable routes, heading structure, meaningful HTML text, internal navigation, Open Graph/social metadata, justified structured data, image metadata, URLs, and duplicate/thin content.

For WebGL/canvas experiences, ensure important content has an accessible crawlable HTML representation. Never keyword-stuff or invent claims.
