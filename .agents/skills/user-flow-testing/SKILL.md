# User Flow Testing
Identify critical journeys, run the application with established commands, and exercise relevant navigation, clicks/taps, typing, scrolling, resizing, loading, empty, error, and back-navigation states. Test representative desktop/mobile viewports when practical.

Report failures with severity, flow, reproduction steps, expected behavior, actual behavior, and evidence. If browser-level capability is unavailable, state that explicitly. Do not modify source unless separately asked.
