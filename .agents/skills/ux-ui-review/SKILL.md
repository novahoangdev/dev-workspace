# UX/UI Review
Evaluate first-impression clarity, hierarchy/scanability, navigation/discoverability, CTA priority, typography, spacing, density, consistency, feedback/affordances, mobile usability, cognitive load, and user journey.

Separate blocking issues, important improvements, and optional polish. Preserve the project's visual identity unless redesign is requested. Prefer concrete improvements over subjective taste.
