# Web Performance
Measure before optimizing and measure again afterward. Check relevant LCP/INP/CLS, initial payload, JS bundle, code splitting/lazy loading, images/fonts, third-party scripts, hydration/client boundaries, long tasks/rerenders, caching/compression/preload/prefetch, and layout shift.

Do not add memoization or complexity without evidence. Distinguish measured findings from hypotheses.
