# WebGL Performance
Measure where possible. Check draw calls, material/geometry duplication, textures, shaders, shadows/lights, render-loop work, unnecessary updates, DPR, loading, GPU memory, and disposal. Prioritize mobile/low-power devices without simplifying away required visual experience.
