# Mac Setup Safety
For meaningful machine changes check sudo, overwrite risk, backup/merge path, reversibility, opt-out, architecture compatibility, rerun behavior, and partial failure. Flag destructive commands, remote pipe-to-shell execution, and silent replacement of user config.
